#### Understanding LLMs

LLMs like GPT-4, Claude, and Gemini are models with different strengths, tailored for specific tasks.
Tokens: Basic units of processing for LLMs; smaller components of words that models consume, affecting computation costs and limits.
Context Window: The maximum number of tokens an LLM can handle at once.

**Temperature**
A setting in LLMs that determines the creativity of the output, lower values yield more deterministic and precise results while higher values offer more creative and varied responses.

**Token Cost**
Input Tokens: Sent to the model as part of the request.
Output Tokens: Generated by the model in response, typically more expensive to produce.

**Model Tiers**
LLMs are available in various tiers (Frontier, Mid-range, Lightweight) with
varying costs. Choose a model based on the complexity of the task to
optimize budget and performance.
